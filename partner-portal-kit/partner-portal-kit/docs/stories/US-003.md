# US-003 Account Manager Workflow

**As** an account manager **I want** to review submitted applications **so that** only suitable partners go to legal.

Build: Kaleo `AM Review` task, `workflowAction` endpoints, `partner-admin-ui` review screen.

## Acceptance criteria
- [ ] AC1 Notification: assigned AM gets email and in-app notification on submit and resubmit.
- [ ] AC2 Queue: AM sees applications in `approvalPending` assigned to them, oldest first, with days waiting.
- [ ] AC3 Detail: tabs Company, Contacts, Compliance, POS, Questionnaire, Documents, Invitation (invited partner details: who, when, resend count). Watchlist and existing-company flags shown at the top.
- [ ] AC4 Request revision: requires at least one comment (general or per section). Status `revisionRequested`, `revisionRequestedBy = am`, `PM_REVISION` with comments and link.
- [ ] AC5 Approve: optional comment; status `underLegalReview`; legal task created; `PM_TO_LEGAL`.
- [ ] AC6 Existing-company applications: Approve moves straight to `authorized` (skip legal) per open question 5.
- [ ] AC7 Timeline: all status changes and comments, newest first.
- [ ] AC8 Permissions: an AM cannot act on applications assigned to another AM.

## Tests
- Workflow action endpoint tests for approve and revision.
- End to end: submit → AM requests revision → partner resubmits → AM approves → in legal queue.
