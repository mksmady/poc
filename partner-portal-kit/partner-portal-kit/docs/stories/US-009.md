# US-009 Product Sync / Import

**As** an admin **I want** to load the product catalog into Liferay once.

Build: `partner-catalog-batch` client extension with batch files in load order.

## Acceptance criteria
- [ ] AC1 Load order: vocabulary and categories → specifications → products → SKUs → images → visibility (account groups).
- [ ] AC2 Every item carries an external reference code from the source system, so a rerun updates instead of duplicating.
- [ ] AC3 A dry run in a lower environment produces a reconciliation report: counts per type, failures with reasons.
- [ ] AC4 Errors raise `PM_ADMIN_ALERT`.
- [ ] AC5 The source-to-Liferay field mapping is documented in `client-extensions/partner-catalog-batch/MAPPING.md`.

## Tests
- Import a 20-product sample twice; counts stay the same the second time.
