# US-008 Notification Management

All rows of `docs/notifications.md`.

## Acceptance criteria
- [ ] AC1 Every template exists in `partner-batch` with ERC = template code.
- [ ] AC2 Invitation, submission confirmation, revision request, approval, rejection, contract status, welcome, administrative alerts and reminders fire on the events listed.
- [ ] AC3 Internal users also get an in-app notification where the table says so.
- [ ] AC4 No email contains a stored secret; link tokens are only in the sent message.
- [ ] AC5 Failures to send raise `PM_ADMIN_ALERT`.

## Tests
- One integration test per template using a captured mailbox.
