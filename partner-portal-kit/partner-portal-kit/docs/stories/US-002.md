# US-002 Partner Registration

**As** an invited partner **I want** to register my company through the invitation link **so that** my application can be reviewed.

Build: `partner-service` public API (`/public/registration/*`), `partner-registration` custom element, child objects.

## Acceptance criteria
- [ ] AC1 Link: valid token opens the wizard; invalid, revoked or expired token shows "This link is no longer valid. Ask your account manager for a new invitation." First valid open moves status to `registrationInProgress`.
- [ ] AC2 Steps: Questionnaire, Company, Contacts, Compliance, POS locations, Documents, Review. Back and Next keep data.
- [ ] AC3 Draft: Save draft at any step; returning with the same link restores everything until expiry.
- [ ] AC4 Company: legal name, registration number, VAT ID, address, country, website, employee band.
- [ ] AC5 Contacts: at least one `primary` contact; add/remove more.
- [ ] AC6 Compliance: sanctions declaration and GDPR consent required; certifications and notes optional.
- [ ] AC7 POS: at least one location; name, address, type, categories.
- [ ] AC8 Documents: trade register extract and VAT certificate required; PDF/JPG/PNG; max `maxUploadMb`; file type sniffed server-side.
- [ ] AC9 Existing company: VAT or registration number matching an authorized Account switches to existing-company mode (company step read-only, `existingCompany = true`). A match on a terminated company sets `watchlistMatch = true` silently.
- [ ] AC10 Submit: server validates all required data; on success status `submitted` → workflow → `approvalPending`; partner sees a confirmation page; `PM_SUBMITTED` sent.
- [ ] AC11 After submit the wizard is read-only until a revision is requested.
- [ ] AC12 No Liferay user exists before authorization. Password creation and forgot password only work after activation (see US-005).

## Tests
- Unit: registration controller (token checks, validation, upload limits), company lookup.
- Custom element: step navigation, draft restore, validation messages (React Testing Library).
- End to end: full wizard with a valid token through to `approvalPending`.
