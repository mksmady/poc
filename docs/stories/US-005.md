# US-005 Partner Lifecycle Management

**As** an account manager or admin **I want** to activate, deactivate and track partners **so that** portal access always matches the partner's status.

Build: `ActivationService` in `partner-service`, deactivate/reactivate endpoints, history view.

## Acceptance criteria
- [ ] AC1 Activation on `authorized`: create the Account (or reuse for existing company), create the User for the primary contact, assign account role Partner Admin, add to the partner site, send `PM_APPROVED` with the set-password link (valid `activationLinkHours`).
- [ ] AC2 Welcome: after the first successful password set or login, send `PM_WELCOME` once.
- [ ] AC3 Forgot password works for active partner users only (Liferay default).
- [ ] AC4 Deactivate: reason required; Account inactive, all its users inactive, sessions ended; status `deactivated`; `PM_DEACTIVATED`.
- [ ] AC5 Reactivate: reverse of AC4; status `authorized`.
- [ ] AC6 History: every status change visible with actor, time and reason; history cannot be edited or deleted.
- [ ] AC7 Idempotent: running activation twice does not create duplicate accounts or users.

## Tests
- `ActivationServiceTest` with a mocked Liferay client (AC1, AC4, AC5, AC7).
- End to end: authorized partner logs in; after deactivate, login fails.
