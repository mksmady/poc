# US-001 Partner Invitation Management

**As** an account manager **I want** to invite a prospective partner by email **so that** they can register through a secure link.

Build: `partner-batch` (PartnerInvitation), `partner-service` (`InvitationController`, `TokenService`, object action `invitation-created`, daily job), `partner-admin-ui` (Invitations view).

## Acceptance criteria
- [x] AC1 Create: form with email, first name, last name (all required, email format checked). Saving creates a PartnerInvitation and a PartnerApplication in `invitationSent`.
- [x] AC2 Duplicate: an `active` invitation for the same email is refused with "An active invitation already exists for this email". A domain or VAT on the terminated watchlist shows a warning but can proceed.
- [x] AC3 Token: 32 random bytes, URL-safe base64; only SHA-256 hash stored; link `/web/partners/register?t=<token>`.
- [x] AC4 Expiry: `expiresAt = sentAt + PartnerSettings.invitationExpiryDays` (default 30). Changing the setting affects new invitations only.
- [x] AC5 Email: `PM_INVITE` sent to the invitee with name, AM name, link and expiry date.
- [x] AC6 Resend: allowed for `invitationSent`, `registrationInProgress`, `expired`. Old token revoked, new token and expiry, `resendCount + 1`, status back to `invitationSent` if `expired`. Draft data is kept.
- [x] AC7 Dashboard (`partner-admin-ui` view `invitations` over `GET /api/invitations?tab=&search=`): list with tabs All / Invitation sent / In progress / Expiring in 7 days / Expired; search by name, email, company; columns invitee, email, status, sent, expires, reminders; AM sees own, admin sees all.
- [x] AC8 Reminders: daily job sends `PM_INVITE_REMINDER` on each day in `reminderDays` while status is `invitationSent` or `registrationInProgress`; never twice on one day.
- [x] AC9 Expire: daily job sets `expired` after `expiresAt`, notifies AM.

## Tests
- Unit: `TokenServiceTest` (hash, constant-time compare, revoke), `InvitationControllerTest` (AC1, AC2, AC6), `DailyJobTest` with fixed clock (AC8, AC9).
- End to end: create invite as AM → email captured (MailHog/GreenMail) → link opens wizard; resend → old link refused.
