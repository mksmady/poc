# Partner Portal — Claude Code starter kit

Specs and Claude Code configuration for building the partner onboarding portal on Liferay DXP
with Objects and client extensions.

1. Copy this folder into an empty Git repository (keep the hidden `.claude/` folder).
2. Open it with Claude Code and run `/implement-story US-001` after build plan steps 0 to 2,
   or simply ask Claude Code to "start build plan step 0".
3. Answer the items in `docs/open-questions.md` when you can.

Start with `CLAUDE.md`.
